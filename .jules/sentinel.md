## 2024-05-18 - Prevent XSS in AI Chat Markdown Renderer
**Vulnerability:** The AI chat component (`src/pages/IA.jsx`) used `dangerouslySetInnerHTML` to render markdown-like text (bolded with asterisks) from the AI's or user's messages. This exposed the application to Cross-Site Scripting (XSS) if the `msg.content` contained malicious HTML or scripts.
**Learning:** Using `dangerouslySetInnerHTML` to inject simple text formatting opens the door to XSS attacks, even if the primary source is an AI. It's unsafe to trust dynamically generated string content. When refactoring away from it using array mapping and `.split()`, one must ensure React handles possible `undefined` string content by using optional chaining to avoid white screen application crashes.
**Prevention:** Avoid `dangerouslySetInnerHTML` for user or dynamically generated text formatting. Prefer safe React-based string splitting and mapping to render elements safely without requiring external sanitization dependencies. When doing so, use optional chaining `?.` or fallbacks on the target string to prevent React rendering crashes.
