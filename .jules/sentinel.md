## 2024-05-24 - Cross-Site Scripting (XSS) via dangerouslySetInnerHTML in IA Chat
**Vulnerability:** The AI chat component (`src/pages/IA.jsx`) used `dangerouslySetInnerHTML` to render bold text `*text*` by blindly replacing it with `<b>text</b>` strings via regex replacement on `msg.content`. If `msg.content` contains unescaped HTML tags (e.g. `<script>alert(1)</script>` or `<img src=x onerror=alert(1)>`), they would be evaluated as raw HTML by React, leading to a Cross-Site Scripting (XSS) vulnerability.
**Learning:** Avoid using `dangerouslySetInnerHTML` for simple text formatting like bolding when possible. Even if the text source is theoretically trusted (like AI responses), an AI could be manipulated into generating malicious payloads, or the content could be intercepted/spoofed.
**Prevention:** Use React-based array mapping with regex `.split()` and capture groups. This safely splits the string and maps matching elements to React components (like `<b>`), allowing React to natively escape all string content and prevent XSS without requiring external sanitization libraries.
