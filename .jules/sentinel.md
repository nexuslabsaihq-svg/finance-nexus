## 2024-05-18 - [HIGH] XSS Vulnerability in IA Chat Output Rendering
**Vulnerability:** The AI chat page (`src/pages/IA.jsx`) used `dangerouslySetInnerHTML` combined with regex string replacement to format bold text (`*bold*` to `<b>bold</b>`) from chat messages. This exposed the application to Cross-Site Scripting (XSS) if any malicious HTML tags were returned in the chat message content.
**Learning:** Formatting plain text markers like markdown directly via `dangerouslySetInnerHTML` is extremely unsafe, as it trusts the raw HTML output and assumes only the target replacement happens, but other parts of the string might contain HTML. In this codebase, safely rendering formatting without DOMPurify is achieved via `.split()` with capture groups.
**Prevention:** Avoid `dangerouslySetInnerHTML`. Instead, split the text using regex capture groups (e.g., `/(\*[^*]+\*)/g`) and map over the array. Use `i % 2 === 1` to safely wrap the formatted elements in JSX tags while returning strings for unformatted parts directly to prevent XSS and ReferenceErrors.
